# 毕业论文写作提纲

## 建议题目

《基于 FastAPI 与 Vue 的智能题库及自适应复习系统设计与实现》

如果学校更强调 AI，可使用《面向多格式学习资料的智能题库生成与复习系统设计与实现》，但必须提供真实导入样本与评价数据。

## 第一章 绪论

- 研究背景：学习资料非结构化、题库整理成本高、复习缺少反馈闭环。
- 研究意义：降低建库成本，把导入、练习、错题与考试连接起来。
- 国内外现状：题库应用、在线考试、间隔重复和大模型结构化抽取。
- 本文工作：系统实现、关键流程、测试与评价。

## 第二章 需求分析

- 用户角色：游客、学生、管理员。
- 功能需求：题库、导入、练习、错题、考试、统计、学习小组、反馈。
- 非功能需求：移动端适配、安全、可恢复任务、可维护性和可部署性。
- 用例图建议：用户导入题库、开始练习、参加考试；管理员处理用户与反馈。

## 第三章 技术选型与总体设计

- Vue 3、TypeScript、Pinia 和 Vite 的职责。
- FastAPI、Pydantic、SQLAlchemy 和 Alembic 的职责。
- SQLite 与 PostgreSQL 的适用边界。
- OpenAI 兼容接口、Redis 可选限流和 Docker 部署。
- 引用 `01-system-architecture.md` 的总体架构图。

## 第四章 数据库与模块设计

- 引用 `02-database-design.md` 的实体分组和 ER 图。
- 重点解释 `QuestionBank`、`Question`、`PracticeRecord`、`WrongRecord`、`UserQuestionReview`、`ImportTask`。
- 说明唯一约束、级联删除、幂等提交和迁移机制。

## 第五章 核心功能实现

### 5.1 认证与权限

说明 Cookie/JWT 兼容、游客账号、角色与资源所有权校验。

### 5.2 多格式 AI 导入

说明文件提取、切块、模型调用、JSON 校验、去重、持久任务、预览确认和失败恢复。展示成功与失败样本，不只展示理想结果。

### 5.3 练习与间隔复习

说明随机取题、统一判分、幂等提交、错题聚合、复习等级和下次复习时间。

### 5.4 正式考试与统计

说明试卷配置、题目分值、提交评分、排行榜和所有者统计。

### 5.5 移动端交互

说明响应式布局、安全区域、沉浸式练习、键盘视口和深浅主题。

## 第六章 系统测试与结果分析

- 使用 `03-testing-and-evaluation.md` 的测试矩阵与命令。
- 展示接口测试、前端组件测试、构建、安全扫描和真机测试结果。
- AI 导入部分至少选择小、中、大三类文档，统计题目召回、有效率、耗时和人工修订量。
- 讨论失败案例、上游模型波动和 WebView 差异。

## 第七章 总结与展望

- 总结已完成的闭环，而不是罗列页面数量。
- 展望可写模型评测集、向量检索、PostgreSQL JSONB、多实例任务队列和原生移动端。

## 可作为创新点的内容

- 面向长文档的分块解析、告警和缺题重试机制。
- 导入任务持久化与人工确认，降低页面退出和上游超时造成的数据丢失。
- 练习提交幂等、错题聚合与间隔复习状态联动。
- 同一题库同时服务于个人练习、公开分享、学习小组和正式考试。

创新点必须由代码、测试或实验数据支持，不能只凭界面截图下结论。
