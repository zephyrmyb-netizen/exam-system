# 全量参考页面一致性落地

- 执行时间：2026-07-14
- 执行窗口：Codex
- 任务目标：以 `exam-platform-ui` 的交接文档、设计令牌和八个页面参考为依据，逐页将现有学习宝前端对齐为同一套移动端学习界面，同时保持真实 API 数据和既有业务交互。
- 范围：仅修改 `frontend/src/` 中直接对应的布局、视图、组件、样式、路由和测试，以及 `frontend/src/data/releaseNotes.ts`。

## 实际变更

- 将首页、题库、导入、练习、考试和个人中心统一到 420px 移动端玻璃学习界面，并保留深色模式语义变量。
- 将底部导航固定为首页、题库、导入、我的四项；练习和考试答题页进入沉浸模式，隐藏外层导航。
- 新增 `/practice/:courseId`、`/exam/:examId`、`/profile` 兼容别名，保持现有路由和 API 路径可用。
- 练习完成状态接入真实用时、正确率、答对/答错统计；完成后提供错题本入口和返回题库入口。
- 考试答题页接入基于真实开始时间和时限的倒计时、答题卡和真实结果展示；后端未提供的字段使用 `--`，未伪造样例数据。
- AI 导入界面保持已有异步任务恢复和分块进度，只调整与参考流程对应的阶段表达与小屏布局。
- 新增路由、练习中心、考试结果等针对性测试，并新增 `v2.7.9` 更新公告。
