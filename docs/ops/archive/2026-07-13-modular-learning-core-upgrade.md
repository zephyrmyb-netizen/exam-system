# 2026-07-13 模块化学习核心升级

## 目标

稳定学习宝两个高频流程：刷题会话与 AI 文件导入。将状态从页面临时变量中抽离，减少重复刷题、切页丢导入进度和移动端交互冲突。

## 范围

- 前端：刷题会话状态机、导入任务接续、练习页动效和移动端交互。
- 后端：可查询的导入任务契约与最小持久化实现；不调整既有业务 API 的语义。
- 不触碰：认证、题库权限、考试业务、已有 Pencil 参考文件。

## 验收

- 题目只在会话未完成时请求下一题，题库耗尽后稳定停在总结状态。
- 切出并回到导入页时，任务状态可恢复且不会误报完成。
- 练习与导入模块均有针对性自动化测试。
- 前端 lint/test/build，后端 pytest/security_check 通过。
