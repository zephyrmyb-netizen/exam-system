# Noto Sans SC Variable

The frontend self-hosts Noto Sans SC Variable through
`@fontsource-variable/noto-sans-sc` version 5.2.10. Vite bundles the package's
WOFF2 files with the application, so no font is fetched from Google Fonts or
another CDN at runtime.

- Typeface author: Google Inc.
- Package homepage: https://fontsource.org/fonts/noto-sans-sc
- npm package: https://www.npmjs.com/package/@fontsource-variable/noto-sans-sc
- Package repository: https://github.com/fontsource/font-files
